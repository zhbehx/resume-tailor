# Bullet 公式与量化换算

## 核心公式：XYZ

> 通过 **X**（做法），做到 **Y**（结果），量化 **Z**（影响）。

三种语序都行，选读起来最顺的：

1. `把 {对象} 从 {A} 改到 {B}，{指标} 提升 {Z}`（结果前置，最有力）
2. `通过 {做法}，{指标} 提升 {Z}，覆盖 {规模}`（过程清楚，适合技术岗）
3. `{动作} {对象}，{规模}，{结果}`（简洁，适合高密度排版）

## 20 条 bullet 公式

### 效率类
1. `把 {流程} 从 {N} 步压到 {M} 步，{指标} 从 {A} 提到 {B}`
2. `用 {工具/脚本} 把 {重复工作} 从 {T1} 缩到 {T2}，每月省 {H} 小时`
3. `重构 {模块}，{性能指标} 从 {A} 降到 {B}（{QPS} 下）`
4. `把 {报表/看板} 自动化，{N} 人不再手工统计`

### 增长类
5. `{渠道} 从 0 做到 {规模}，{CAC/ROI} 达到 {值}`
6. `{活动} 带来 {新增/转化} {N}，成本 {C} 元/个`
7. `把 {漏斗环节} 转化率从 {A} 提到 {B}，月增 {收入/用户}`
8. `{内容/SEO} 带来自然流量 {N}/月，占比从 {A} 到 {B}`

### 收入与成本
9. `{产品线} 年营收从 {A} 做到 {B}`
10. `{采购/供应商} 谈判降价 {X}%，年省 {金额}`
11. `{套餐/定价} 调整后 ARPU 从 {A} 到 {B}`
12. `{流失} 降低 {X} 个点，相当于年挽回 {金额}`

### 质量与风险
13. `{系统} 故障率从 {A} 降到 {B}，全年 {N} 次零事故`
14. `建立 {规范/流程}，{缺陷/投诉} 下降 {X}%`
15. `提前 {T} 发现 {风险}，避免 {金额/工期} 损失`
16. `通过 {审计/认证}，覆盖 {N} 个系统`

### 组织与协作
17. `带 {N} 人团队，{周期} 内交付 {项目}，按期率 {X}%`
18. `推动 {N} 个部门对齐 {流程}，{环节} 周期从 {A} 缩到 {B}`
19. `搭 {机制/文档体系}，新人上手从 {T1} 缩到 {T2}`
20. `培训 {N} 人，{技能} 考核通过率 {X}%`

## 强弱动词对照

| 弱（别用） | 强（替换） |
| --- | --- |
| 负责 | 主导、统筹、落地、搭 |
| 参与 | 承担…模块、独立完成、推动 |
| 协助 | 支撑（+具体产出）、配合完成 X |
| 配合 | 对齐、协调、推动 |
| 跟进 | 推进、闭环、交付 |
| 做了 | 搭建、重构、上线、验证 |
| 优化了 | 把 A 改成 B，指标从 X 到 Y |
| 提升了效率 | 省 N 小时/月、周期从 A 到 B |

> 规则：动词后面必须跟**可验收的对象**。“主导”后面接不了具体事，就是空话。

## 没有数字时怎么换算

数字不必是后台导出的精确值，**可以换算，不能编造**。

| 有 | 换算成 |
| --- | --- |
| 每天做 N 次 | 月 N×22 次 / 年节省 X 小时 |
| 服务一个团队 | 覆盖 N 人、日均 N 单 |
| 处理过很多投诉 | 月均 N 起、闭环率 X% |
| 项目做了 3 个月 | 周期从 A 缩到 B、提前 N 天上线 |
| 客户数量记不清 | 峰值并发 N、累计服务 N 家 |
| 质量变好了 | 返工率从 A% 降到 B%、客诉从 N 降到 M |
| 写得快 | 单篇从 T1 到 T2、月产出 N 篇 |

**三步换算**：先问“这件事的规模单位是什么”（人数/单量/时长/金额/次数）→ 再问“改善前的基线是多少”（哪怕是估算）→ 最后写成“从 A 到 B”。

数字写法：`1.2 万` 比 `12000` 好读；`约` `左右` 只能出现在你确实估算的地方，且不要每句都加。

## 一段原文改写的完整示例

原文：
> 负责公司公众号运营，参与内容策划，配合市场部完成活动推广，提升了品牌影响力。

改写：
> 把公众号从周更 2 篇改为按选题排期周更 4 篇，6 个月粉丝 1.8 万 → 4.3 万，单篇平均打开率 4.1%（行业均值约 2.5%）；策划 3 次联名活动，带来新增 6,200，获客成本比投放低 71%。

改了什么：加了规模（粉丝数）、加了基线对比（行业均值）、给了成本对比、删掉了“参与/配合/提升影响力”三个空词。
