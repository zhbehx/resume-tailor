# 案例：产品经理 → 增长产品（完整流程）

## 用户输入

> 我做了 4 年 B 端产品，想转增长岗，帮我改简历。

**JD 摘录（用户提供）**

> 增长产品经理｜3–5 年｜负责新渠道增长，搭建实验体系，通过数据驱动提升注册与留存转化；要求熟悉 A/B 测试、漏斗分析、埋点，有从 0 到 1 增长项目经验者优先；跨部门推动能力强，抗压。

## Step 1 · JD 拆解（先让用户确认）

| 类型 | 内容 |
| --- | --- |
| 硬性 | 3–5 年经验、A/B 测试、漏斗分析、埋点、数据驱动 |
| 加分 | 从 0 到 1 增长项目 |
| 隐性 | “跨部门推动 + 抗压” → 协作摩擦大、人手紧；“实验体系”“从 0 到 1” → 团队还没有方法论，要能自己搭 |

**一句话判断**：真正在找的是 **P6 增长产品，能独立把一条新渠道从 0 跑到有数据，并且团队现在缺会做实验设计的人**。

⚠️ 关键判断：B 端经历不直接对口，但**“B 端复杂流程的漏斗拆解”是可迁移资产**——这是整份简历要打的那张牌，而不是掩盖 B 端背景。

```
$ python scripts/check_jd_match.py --jd jd.txt --resume old.txt

关键词覆盖：0%  （JD 5 个能力词，命中 0 个）
量化率    ：0%  （0/8 条 bullet 含数字）
弱动词    ：6 处
综合评分  ：5.0/100

JD 高频但简历缺失（优先补）：增长、A/B 测试、漏斗分析、留存、埋点
弱动词句（改成强动词 + 成果）：
  第 1 行 [负责] - 负责 B 端客户管理系统的需求梳理与迭代
  第 2 行 [参与] - 参与销售与实施团队的需求评审
  第 4 行 [协助] - 协助数据团队搭建客户健康度看板
  第 6 行 [配合] - 配合市场部完成两次产品发布会
  第 7 行 [负责] - 负责客户投诉处理，维护客户关系
  第 8 行 [参与] - 参与年度产品规划
```

结论：**5 分。先补证据，别润色。** 这个分数不是写作水平问题，是「JD 要的词一个都没有、每句话都无法验收」。

## Step 3 · 改写（原文 → 改写）

| 原文 | 改写 | 为什么 |
| --- | --- | --- |
| 负责 B 端客户管理系统的需求梳理与迭代 | 重构客户管理系统的线索分配逻辑，销售跟进响应时间从 26 小时缩到 4 小时，覆盖 340 家客户 | 对应隐性要求“能推动落地”，同时给出规模 |
| 参与销售与实施团队的需求评审 | 拉通销售、实施、客服 3 个团队做双周需求评审，需求平均等待周期从 18 天降到 6 天 | 对应“跨部门推动”，量化周期 |
| 协助数据团队搭建客户健康度看板 | 设计客户健康度指标体系（6 个维度、23 个埋点），续费率从 71% 提到 79% | 把“协助”换成主导，并补上埋点（JD 硬性词） |
| 熟悉数据分析 | 用 SQL 独立做漏斗分析，定位注册环节流失点，改造后注册完成率从 54% 提到 68% | 把“熟悉”变成可验证的动作与结果 |
| （无） | 自建 A/B 测试流程：定义分流规则与显著性判断标准，半年跑 14 组实验，其中 5 组上线 | 补 JD 硬性词“A/B 测试”，且这是“从 0 到 1 搭体系”的证据 |

## Step 4 · 改写后重跑

```
$ python scripts/check_jd_match.py --jd jd.txt --resume new.txt

关键词覆盖：80%  （JD 5 个能力词，命中 4 个）
量化率    ：100%  （9/9 条 bullet 含数字）
弱动词    ：0 处
综合评分  ：90.0/100

JD 高频但简历缺失（优先补）：增长
```

**5.0 → 90.0。** 剩下的 10 分缺口很具体：JD 里的「增长」这个词，整份简历一次都没出现。

这不是文字问题，是经历问题。补救方式不是硬塞关键词（面试一问就露），而是在面试里主动给出迁移逻辑：

> 「B 端我做的是渠道分销的转化优化，逻辑和 C 端拉新一样：先定义口径，再做分层实验。我整理过一份迁移方案，可以现场讲 5 分钟。」

## Step 5 · 位置怎么排

```
一句话定位：4 年 B 端产品，把复杂流程拆成可量化漏斗，做过 14 组增长实验
核心成果 3 条：线索分配（26h→4h）｜健康度体系（续费 71%→79%）｜注册漏斗（54%→68%）
工作经历：倒序，B 端经历在前，但每条都按“漏斗 + 数字”写
项目：只留“客户健康度体系”“注册流程改造”两个
技能：SQL、A/B 测试、埋点设计、漏斗分析（都是 JD 提过的）
教育：一行
```

## 这个案例做对了什么

1. **没有把 B 端经历藏起来**，而是把它翻译成增长岗听得懂的语言（漏斗、指标、实验）。
2. **每个 JD 硬性词都有一条证据**，且证据里带数字。
3. 改写后重跑脚本，用数字证明改动有效——而不是「我觉得好多了」。
4. 主动指出剩下的缺口（「增长」这个词一次没出现），并给出补救话术而不是硬塞关键词。
5. 弱动词只在**主语位置**才算：`销售跟进响应时间从 26 小时缩到 4 小时` 里的「跟进」是名词搭配的一部分，实测报 0 处；而 `这次改版我参与了其中的设计环节` 的「参与」仍会被抓到。
